SECTION 01Bernstein’s Condition

Directly computing or bounding the MGF can be impractical. An alternative is to control the polynomial moments of X.

Definition · Bernstein’s Condition

Let X have mean μ = E[X] and variance σ² = E[(X − μ)²]. Bernstein’s condition with parameter b > 0 holds if

|E[(X−μ)k]|≤12k!σ2bk−2,k=2,3,…

Claim · Bernstein’s Condition Implies Sub-Exponentiality

If X satisfies Bernstein’s condition, it is sub-exponential with parameters (ν, α) = (√2σ, 2b).

Proof of the Claim

Expand the exponential. The linear term vanishes because E[X − μ] = 0:

E[eλ(X−μ)]=1+λ2σ22+∑k=3∞λkE[(X−μ)k]k!

Applying Bernstein’s condition term by term gives

E[eλ(X−μ)]≤1+λ2σ22+λ2σ22∑k=3∞(|λ|b)k−2

For each term, λᵏ E[(X − μ)ᵏ] ≤ |λ|ᵏ |E[(X − μ)ᵏ]|. Thus the bound on |E[(X − μ)ᵏ]| controls the term regardless of its sign.

For |λ| < 1/b, summing the geometric series gives

E[eλ(X−μ)]≤1+λ2σ221−b|λ|≤eλ2σ221−b|λ|

The last step uses 1 + u ≤ eᵘ for u ≥ 0.

Restricting to |λ| < 1/(2b) makes 1 − b|λ| ≥ 1/2, so

E[eλ(X−μ)]≤eλ2σ2=e(2σ)2λ22

This has the sub-exponential form with ν = √2σ and α = 2b. The smaller interval simplifies the MGF bound; the preceding bound remains valid on the larger interval |λ| < 1/b.

SECTION 02Bernstein-Type Bound

We could apply the preceding sub-exponential tail bound. Keeping the more precise MGF bound from the proof gives a sharper result.

Formulation · Bernstein-Type Bound

For any X satisfying Bernstein’s condition,

E[eλ(X−μ)]≤eλ2σ221−b|λ|,|λ|<1b

The corresponding two-sided concentration bound is

P(|X−μ|≥t)≤2e−t22(σ2+bt),t≥0

For σ² > 0, choose λ = t/(σ² + bt) ∈ [0, 1/b) in the Chernoff bound. Substitution gives the exponent −t²/[2(σ² + bt)]. The same argument applies to −(X − μ); adding the two tails gives the factor of 2. This convenient choice of λ need not be the exact optimizer. If σ² = 0, X = μ almost surely.

SECTION 03Bounded Variables and Comparison with Hoeffding

Example · A Bounded Variable Satisfies Bernstein’s Condition

Suppose |X − μ| ≤ b. For every integer k ≥ 2,

|E[(X−μ)k]|≤E[|X−μ|k]≤bk−2σ2≤k!2σ2bk−2

Thus Bernstein’s condition holds. Hoeffding uses the range [μ − b, μ + b], giving

P(|X−μ|≥t)≤2e−t22b2

Bernstein instead uses the actual variance σ²:

P(|X−μ|≥t)≤2e−t22(σ2+bt)

(1) For small deviations with bt ≪ σ², the Bernstein bound has approximately the Gaussian form 2 exp(−t²/(2σ²)).

(2) Since σ² ≤ b², the variance can be much smaller than the range-based scale b². Bernstein is tighter than the displayed Hoeffding bound when σ² + bt < b², though it is not uniformly tighter for every t.

The improvement can be substantial when a variable occasionally takes large values but has small variance. Variance-based control often plays a key role in obtaining optimal rates in statistical problems, as we will see later.

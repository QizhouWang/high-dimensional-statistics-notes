# High-Dimensional Statistics Notes

Personal lecture notes on non-asymptotic theory and high-dimensional statistics.

## Files

- `非渐近理论与集中不等式.html`: lecture content.
- `assets/lecture.css`: reusable lecture styles.
- `index.html`: website entry point linking to the lecture.

## Publishing

Enable GitHub Pages from the `main` branch, using the repository root (`/`). Updates pushed to `main` will publish automatically.

PDF books and source photographs are kept locally and excluded from this repository.

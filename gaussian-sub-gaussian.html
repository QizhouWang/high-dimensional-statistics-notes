SECTION 01Gaussian Tail Bounds and Sub-Gaussian Variables

The Chernoff bound depends on the growth rate of the moment generating function. It is therefore natural to classify random variables by their MGF behavior. Information about a particular class gives us more control over its MGF and can lead to more specific, potentially tighter tail bounds.

We first consider Gaussian-like random variables. We proceed in four steps: (1) start with a familiar Gaussian variable, whose MGF can be computed explicitly; (2) observe that the tail-bound derivation depends on the MGF’s growth, rather than on the variable being Gaussian; (3) introduce sub-Gaussian variables, whose centered MGFs are bounded by the same Gaussian form. Sub-Gaussian variables satisfy the same form of Chernoff bound as Gaussian variables. (4) show that many commonly used types of random variables are sub-Gaussian.

Gaussian Tail Bounds

Setting

Let X ∼ N(μ, σ²), with σ > 0. Its moment generating function is

E[eλX]=eμλ+σ2λ22,λ∈R

Formulation · Gaussian Tail Bound

Substituting the Gaussian MGF into the Chernoff bound gives

infλ≥0{logE[eλ(X−μ)]−λt}=infλ≥0{σ2λ22−λt}=−t22σ2

Therefore, any N(μ, σ²) random variable satisfies the upper-deviation bound

P(X≥μ+t)≤e−t22σ2,t≥0

The Chernoff bound is not sharp for a Gaussian variable: at t = 0, the true tail probability is 1/2, while the bound is 1. To compare them far from the mean, we use the following approximation for large t/σ:

P(X≥μ+t)∼σt2πe−t22σ2,tσ→∞

The expression on the right approximates the true tail probability on the left. Compared with this approximation, the Chernoff bound captures the correct exponential decay but omits the multiplier σ/(t√(2π)).

Its advantage is simplicity and broad applicability: the same argument extends to all sub-Gaussian variables using only a bound on the centered MGF, without knowing the exact distribution. This makes it useful for concentration guarantees. For Gaussian variables, however, it can substantially overestimate the true tail probability, so it is less suitable for precise Gaussian probability estimates. For other sub-Gaussian variables, its tightness depends on the distribution.

SECTION 02Sub-Gaussian Variables

The calculation above relies on the Gaussian form of the centered MGF. This motivates a broader class of random variables with the same MGF bound.

Definition · Sub-Gaussian Variable

A random variable X with mean μ = E[X] is sub-Gaussian if there is a σ > 0 such that

E[eλ(X−μ)]≤eσ2λ22,λ∈R

The constant σ is called a sub-Gaussian parameter.

Formulation · Sub-Gaussian Concentration Bound

Combining the pieces, we conclude that any sub-Gaussian variable satisfies the concentration inequality

P(|X−μ|≥t)≤2e−t22σ2,t≥0

SECTION 03Sub-Gaussian Examples

Claim 1 · A Rademacher Variable Is Sub-Gaussian

A Rademacher random variable ε takes −1 and +1 with equal probability. It is sub-Gaussian with parameter σ = 1.

Proof of Claim 1

Expanding the two exponentials cancels all odd powers:

E[eλε]=e−λ+eλ2=∑k=0∞λ2k(2k)!

Since (2k)! ≥ 2ᵏk!,

∑k=0∞λ2k(2k)!≤1+∑k=1∞λ2k2kk!=eλ22

Rademacher complexity measures how well a function class can fit random signs. Fix samples x₁, …, xₙ and assign independent Rademacher signs ε₁, …, εₙ. For a function class ℱ, its empirical Rademacher complexity is

ℜ^n(ℱ)=Eε[supf∈ℱ1n∑i=1nεif(xi)]

Read this as (1) generate random ±1 labels, (2) choose the function that best aligns with them, and (3) average over the random labels. This ability to fit noise is used to study generalization in machine learning.

Claim 2 · A Bounded Variable Is Sub-Gaussian

Let X have mean zero and take values in [a, b]. Then X is sub-Gaussian with parameter σ = b − a.

Proof of Claim 2

Let X′ be an independent copy of X. For any λ ∈ ℝ,

EX[eλX]=EX[eλ(X−EX′[X′])]≤EX,X′[eλ(X−X′)]

Jensen’s inequality states that, for a convex function g,

g(E[Y])≤E[g(Y)]

Here, hold X fixed and average over X′. The function g(u) = exp(λ(X − u)) is convex, and E[X′] = 0.

Let ε be an independent Rademacher variable. Since X − X′ has a symmetric distribution, it has the same distribution as ε(X − X′). Apply Claim 1 with X and X′ fixed:

EX,X′[eλ(X−X′)]=EX,X′[Eε[eλε(X−X′)]]≤EX,X′[eλ2(X−X′)22]

Since |X − X′| ≤ b − a,

EX,X′[eλ2(X−X′)22]≤eλ2(b−a)22

Thus X is sub-Gaussian with parameter at most b − a.

Introducing an independent copy X′ and then a Rademacher variable is a symmetrization argument, a technique used again in later chapters.

SECTION 04Hoeffding Bounds

Claim · Independent Sums Remain Sub-Gaussian

Just as Gaussianity is preserved by linear operations, so is sub-Gaussianity. In particular, independent sums have the following property. If X₁ and X₂ are independent sub-Gaussian variables with parameters σ₁ and σ₂, then X₁ + X₂ is sub-Gaussian with parameter

SECTION 01Azuma–Hoeffding Inequality

Formulation · Azuma–Hoeffding

Let Dₖ be determined by X₁ᵏ and satisfy E[Dₖ | X₁ᵏ⁻¹] = 0. Suppose there are constants aₖ ≤ bₖ such that Dₖ ∈ [aₖ, bₖ] almost surely. Then

P(|∑k=1nDk|≥t)≤2e−2t2∑k=1n(bk−ak)2,t≥0

Proof of Azuma–Hoeffding

The increments Dₖ need not be independent, so we cannot directly apply the earlier Hoeffding bound for independent sums. Instead, we control their sum’s MGF by conditioning on the past.

Write Sₙ = ∑ₖ₌₁ⁿ Dₖ and cₖ = bₖ − aₖ.

(1) Given X₁ᵏ⁻¹, the variable Dₖ still lies in [aₖ, bₖ] and has conditional mean zero. Apply the bounded-variable sub-Gaussian result to this conditional distribution:

E[eλDk|X1k−1]≤eλ2ck28,λ∈R

(2) Condition on X₁ⁿ⁻¹. Since Sₙ₋₁ is already determined by these inputs,

E[eλSn]=E[eλSn−1E[eλDn|X1n−1]]
E[eλSn]≤E[eλSn−1]eλ2cn28

Repeat this step for n − 1, n − 2, …, 1, ending with S₀ = 0:

E[eλSn]≤eλ28∑k=1nck2

This is a recursive argument: each step removes the last increment and replaces its conditional MGF by a deterministic upper bound. It uses the tower property rather than independence.

(3) Hence Sₙ is sub-Gaussian with parameter squared σ²S = ¼ ∑ₖ₌₁ⁿ cₖ². Substituting this into the two-sided sub-Gaussian tail bound gives the stated result.

SECTION 02Bounded Differences and McDiarmid’s Inequality

We now apply Azuma–Hoeffding to the Doob increments of f(X). The goal is to control their conditional ranges through an easily checked property of f.

Definition · Bounded Differences

Given x, x′ ∈ ℝⁿ, let x\k be x with only coordinate k replaced by x′ₖ:

xj\k={xjj≠kxk′j=k

The function f satisfies the bounded differences property with parameters (L₁, …, Lₙ) if, for every coordinate k and all x, x′,

|f(x)−f(x\k)|≤Lk

Formulation · McDiarmid’s Inequality

If f satisfies this property and X₁, …, Xₙ are independent, then

P(|f(X)−E[f(X)]|≥t)≤2e−2t2∑k=1nLk2,t≥0

Proof of McDiarmid’s Inequality

Use the Doob increments

Dk=E[f(X)|X1k]−E[f(X)|X1k−1]

We show that, given X₁ᵏ⁻¹, Dₖ lies in an interval of length at most Lₖ. Fix the past inputs and write

gk(x)=E[f(X1,…,Xk−1,x,Xk+1n)|X1k−1]

Define the lower and upper endpoints

Ak=infxgk(x)−E[f(X)|X1k−1]
Bk=supxgk(x)−E[f(X)|X1k−1]

Since gₖ(Xₖ) lies between its infimum and supremum, Aₖ ≤ Dₖ ≤ Bₖ almost surely.

By independence, gₖ(x) averages only over the remaining inputs Xₖ₊₁, …, Xₙ. Write Eₖ₊₁ for this expectation. Then

Bk−Ak=supxgk(x)−infxgk(x)
Bk−Ak≤supx,y|Ek+1[f(X1,…,Xk−1,x,Xk+1n)−f(X1,…,Xk−1,y,Xk+1n)]|≤Lk

The first inequality uses supₓ gₖ(x) − infᵧ gₖ(y) = supₓ,ᵧ(gₖ(x) − gₖ(y)) and a − b ≤ |a − b|. The final inequality follows from |E[U]| ≤ E[|U|] and the bounded differences property: the two function values differ only in coordinate k.

Thus Bₖ − Aₖ ≤ Lₖ. Although Aₖ and Bₖ may depend on the past, once X₁ᵏ⁻¹ is given they are fixed. The same conditional-MGF argument used above therefore applies with interval width Lₖ, yielding McDiarmid’s inequality.

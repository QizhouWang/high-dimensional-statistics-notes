SECTION 01Sub-Exponential Variables

Sub-Gaussianity requires tails to decay at least as fast as a Gaussian tail. This excludes many distributions with slower tail decay, such as an exponential distribution. We therefore relax the condition to allow heavier tails.

We introduce sub-exponential variables, then derive their tail bound using the Chernoff approach. The bound has two regimes: a Gaussian form for smaller deviations and an exponential form for larger deviations.

Definition · Sub-Exponential Variable

A random variable X with mean μ = E[X] is sub-exponential if there are nonnegative parameters (ν, α) such that

E[eλ(X−μ)]≤eν2λ22,|λ|<1α

Unlike the sub-Gaussian condition, this Gaussian MGF bound is required only for |λ| < 1/α. When α = 0, the interval is all of ℝ. Every sub-Gaussian variable is therefore sub-exponential with ν = σ and α = 0, but the converse does not hold.

The existence of the moment generating function in a neighborhood of zero is actually an equivalent definition of a sub-exponential variable.

SECTION 04Equivalent Characterizations

Claim · Three Equivalent Ways to Describe Sub-Exponential Variables

For a zero-mean random variable X, the following statements are equivalent.

(1) The MGF has a Gaussian-form upper bound near zero: there are nonnegative parameters (ν, α) such that

E[eλX]≤eν2λ22,|λ|<1α

(2) The MGF is finite near zero: there is a c₀ > 0 such that

E[eλX]<∞,|λ|≤c0

This condition is enough to establish sub-exponentiality, but does not directly give useful values of (ν, α).

(3) The tail probability decays at least exponentially: there are constants c₁, c₂ > 0 such that

P(|X|≥t)≤c1e−c2t,t>0

This exponential tail bound is why these variables are called sub-exponential.
